# P3-03: Hierarchy panel with undo (issue #89)

- Native tail (ABI 4.10, appended after the 4.9 2D physics tail; drafted as 4.3 and renumbered when merged after #179): `editor_destroy_entity`, `editor_get_name`, `editor_duplicate`, `editor_snapshot_take_subtree`, `editor_snapshot_restore_subtree` at offsets 672..704, table size 712 (pinned in test_abi_layout + AbiLayoutTests).
- `editor_destroy_entity` cascades to descendants (DeleteCommand restores them from a subtree snapshot). The 4.7 `editor_delete_entity` (P3-08 drop undo) orphans children instead; both stay.
- Subtree snapshots are component-complete (ecs_get_type walk: data ids copied byte-for-byte, tags re-added, gained components removed) and restore rows with their ORIGINAL ids via ecs_make_alive. Pose rows are read/written with memcpy (P0-05: flecs columns are not 64B-aligned).
- `duplicate()` copies owned components except ChildOf and (Identifier, *) pairs, re-attaches under the source's parent, and names the copy "<name> Copy", then "<name> Copy 2", ... so siblings stay uniquely addressable. The earlier "sibling walk segfaults after duplicate" note did not reproduce after the merge; `engine_editor_hierarchy` (native) and the live managed checks walk the parent after duplicating.
- Managed commands: SpawnCommand and DuplicateCommand share CreateEntityCommand (undo snapshots + destroys the created entity, redo restores the SAME id, so later Rename/Reparent/Delete commands in the history stay valid). RenameCommand, ReparentCommand, DeleteCommand (fresh subtree snapshot per Apply). All run through Inspector.Execute; IEditCommand is IDisposable and the Inspector disposes dropped commands.
- Panel (Engine.EditorApp/HierarchyPanel.cs): TreeView over HierarchyModel; F2/double-click opens an in-place TextBox (Enter commits a RenameCommand, Escape cancels); drag-drop of a row onto another row reparents through ReparentCommand (drop on empty space makes a root; drops onto itself or a descendant are ignored); Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z) undo/redo; context menu Create Empty / Duplicate / Delete.
- Acceptance (EditorApp.Tests, HierarchyPanelGolden): F2 + Enter rename, Ctrl+Z/Ctrl+Y, `window.DragDrop` of C onto A then Ctrl+Z, undoable duplicate, and the `editor_hierarchy_3nested` golden. Pixel goldens run on Linux only (same rule as the shell golden); the structural checks run everywhere.
