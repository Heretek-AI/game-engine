# P5-01 Spike: skeletal mesh + animation clip import (#112)

- cgltf v1.15 (same in-tree source as P5-00): skins expose `cgltf_skin`
  with `joints` (array of `cgltf_node*`), `inverse_bind_matrices`
  (`cgltf_accessor*`, MAT4 float16 per joint, `cgltf_num_components`=16);
  animations expose `cgltf_animation` with `samplers[]` (input=times,
  output=values, `interpolation` enum) + `channels[]` (sampler index,
  `target_node`, `target_path` enum). Enum order matters: the importer
  `static_cast`s `cgltf_animation_path_type` (invalid/translation=1/
  rotation=2/scale=3/weights) and `cgltf_interpolation_type`
  (linear=0/step=1/cubic_spline=2) directly into `AnimTargetPath` /
  `AnimInterpolation` — weights channels are skipped, not cast.
- Key reads via `cgltf_accessor_unpack_floats` (float-only; non-float
  accessors skip the channel, never fail the clip). Times must be finite
  and strictly ascending; value_count must equal key_count * components
  (T/S=3, R=4, x3 for cubicspline in/out/value tangents).
- Joint hierarchy is NOT in skin order: resolved by walking
  `cgltf_node->parent` chains to find each joint's nearest ancestor that
  is also a joint of the same skin, then re-emitted parent-first (BFS)
  so `parent_index` always points at an earlier joint (-1 = root);
  cycles or unreachable joints fail closed (corrupt skin, no partial
  append). Clip `target_joint` indices resolve against that same
  parent-first order (cgltf slot -> emit index map), so they index the
  `.skel` joint array directly. Channels whose target node is not a
  joint of the selected skin are skipped; clips left channel-less are
  skipped. Default `skin_index` = 0.
- Fixture gotchas (in `skeletal_glb_fixture.hpp`): GLB chunk Length =
  payload bytes only (`+8` -> `data_too_short`, same as P5-00 §4.13.3);
  the 6-byte u16 index run needs 2 pad bytes so the u8 JOINTS_0 view
  starts 4-aligned; translation accessor is VEC3 (a VEC4 placeholder
  string is patched before writing — accessor 8 byteLength 24).
- Layouts: `.skel` magic "ENGS" v1, `.anim` magic "ENGA" v1 (LE, IEEE-754
  LE floats, readers bounds-check + fail closed on bad magic/version/
  truncation). Kinds 4/5 wired through engine-pak + ExportPipeline with
  per-kind sub-GUIDs. Test-only entry `SkeletalParseMemory` mirrors the
  worker map -> `cgltf_parse` -> load_buffers sequence in-memory.
- No `engine_abi.h` change (import lives in `engine_assets` + tooling),
  so no ABI bump or regen on this slice.
