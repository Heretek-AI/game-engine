## 2026-11-04 — Import chain (asset_importer.cpp)

- Each level simplifies from its parent (`meshopt_simplify` standard
  practice); a level is kept only when strictly smaller than the parent
  and >= 12 indices (4 triangles). Chain stops at the first level that
  fails to reduce — tiny fixtures (1-triangle GLB) keep 1 level, never 0.
- Existing `test_asset_pipeline` gate (`output<=input tris, lod>=1`, ENGM
  magic) still passes unchanged.

## 2026-11-04 — mesh_lod.hpp selector contract

- Thresholds are fractions of the authored LOD0 reference coverage:
  L0 >= 0.50, L1 >= 0.25, L2 >= 0.125, else L3. `SelectLodIndex` clamps
  (negative -> 3, >= 1 -> 0); NaN fails safe via `!(x >= t)` guards.
- `CrossfadeFactor(level)`: 0 above/inside-safe zone, linear ramp 0 -> 1
  inside the 10%-of-threshold band below each threshold, 0 for LOD3
  (nothing coarser to fade to). Always bounded [0, 1].
