## 2026-11-02 — variance threshold correction (documented, not weakened)
- First run: `worst=0.3020` vs my initial 0.02 guess → FAIL. Root cause: a max-contrast edge (0.1↔0.9) under ±0.5px jitter legitimately re-fires the neighbourhood reject when the jitter delta pushes the reprojected history sample across the edge — one reject step moves ≤ 0.5·0.8 = 0.4. A broken feedback would oscillate full-range 0.8 jumps. Threshold set to 0.5 with the derivation in the header comment; determinism across runs is covered by the golden re-run (verified: re-run without UPDATE → `[PASS] golden`).
