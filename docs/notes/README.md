# Slice notes

One file per roadmap slice: `docs/notes/<slice id>.md` (for example `P0-02.md`).
Each entry is a dated bullet with the command you ran and the output you saw.
Edit only your own slice's file, so parallel PRs never conflict.
`docs/NOTES.md` is frozen history from before the parity roadmap; do not append to it.
See rule 7 in `docs/PARITY_IMPLEMENTATION_PROMPT.md`.
