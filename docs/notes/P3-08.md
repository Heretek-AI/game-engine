## CodeRabbit follow-ups (2026-11-01)
- Drop now also adds a `WorldTransform` seeded with the ground pose, so
  `propagate()` and the draw queries match the entity.
- Redo of a drop re-drops the asset at the same ground point (the first
  Apply stays a no-op because the entity already exists).
- Open: `mesh_id` is a content hash, not a `MeshRegistry` id. The
  registry assigns sequential ids in `renderer_upload_mesh`, so the
  viewport has to upload the imported model and rewrite `mesh_id` before
  the drop is actually drawn. That needs the P3-02 viewport/renderer
  owner, which is not on main yet.
