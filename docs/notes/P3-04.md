# P3-04 notes — Component field metadata from the generator (#90)

## What landed
- ABI 4.24 tail (append-at-end, minor 4.23 → 4.24): `EngineFieldDesc
  { const char* name; uint32_t offset; uint32_t type }` (type enum 0..10:
  f32/i32/u32/bool8/vec2/vec3/vec4/quat/color4/entity/asset-ref; lane sizes
  4/4/4/1/8/12/16/16/16/8/8) + `component_describe` (bulk store),
  `component_field_count`, `component_field_at` (out-param struct fill).
  New entries are plain Cdecl (describe copies strings, may allocate).
- Native store: `GenericSystems::descriptions_` (per-world, name-keyed,
  native-owned string copies). describe requires a prior register
  (NOT_FOUND otherwise); all-or-nothing validation (empty name, duplicate,
  type > 10, offset+lane > size, overlaps → BAD_ARG; count == 0 stores an
  empty description; count > 256 → BAD_ARG); re-describe overwrites
  (hot-reload). field_count returns count or negative ERR; field_at fills
  *out_desc (name aliases native storage) or NOT_FOUND (also OOB).
- Built-ins described automatically in `GenericSystems::register_component`
  (same describe() core): LocalTransform (position vec3 @0, rotation quat
  @12, scale vec3 @28), Camera (fov_y_rad @0, near_z @4, far_z @8,
  is_main u32 @12), MeshRenderer (mesh_id asset-ref @0, base_color color4
  @4), DirectionalLight (direction vec3 @0, shadow f32 @12). Size-checked
  against the live component (drift fails closed = undescribed).
- Generator: stage-1b picks up every partial IComponent struct with fields
  (Tick-less included); stage-2b maps fields all-or-nothing
  (float→f32, int→i32, uint→u32, bool→bool8, Vector2/fixed[2]→vec2,
  float3/Vector3/fixed[3]→vec3, float4/Vector4/fixed[4]→vec4,
  quaternion/Quaternion→quat, Entity→entity, AssetRef<T>→asset-ref;
  skips: non-public, backing fields, Nullable, enums, nested structs,
  FixedString64, float4x4, long/ulong/double/short/byte, pointers, bad
  fixed buffers). Emits `Describe(table, world)` (stackalloc FieldDesc,
  Marshal.OffsetOf per field, ComponentName cache for the component name)
  next to every Register (runnable calls Describe first, unrunnable calls
  Describe then returns -2). Stage-2b always emits exactly one Describe
  (real or no-op) so Register always links.
- Ecs.cs: `ComponentName<T>` made public + Utf8 public (generated Describe
  reuses the cache — byte-identical to the register name).
- Scene: `save/load_scene_with_descriptions` overloads (resolver callback
  over GenericSystems via bridge lambdas; existing save/load delegate to
  the null-describe legacy path). Writer emits named fields in description
  order when count > 0 else the $bytes blob unchanged (f32/i32/u32 numbers,
  bool8 true/false, vec/quat/color4 arrays, entity file-local ids,
  asset-ref raw u64). Reader tries $bytes first (legacy loads), then named
  (zero-init buffer, unknown keys ignored, absent keys zero, atomic
  per-component skip on any field error; named payload for unknown
  component → warn+skip, never register with a guessed align; entity lanes
  zeroed in pass 1 + fixups applied in pass 2). Version stays 1.
- Codegen: ValidateCType + CsType accept `EngineFieldDesc*` /
  `const EngineFieldDesc*` → `FieldDesc*`; emits `FieldDesc` mirror
  (16B) + `FieldType` enum; loader pins `sizeof(FieldDesc) == 16`.

## Acceptance
- GeneratorDriverTests: Health { float Current; int Max } produces
  Describe with Current→F32, Max→I32, Marshal.OffsetOf calls,
  EngineComponentDescribe; null-table Describe → -1.
- Scene round-trip writes `"Engine.Tests.SceneHealth":{"Current":75,"Max":100}`
  (dotted FullName contract; the spec's `"Health"` shape holds for a
  component actually named Health).
- Native test_scene_io: Health {75.0F, 100} named save → file contains
  `"Game.Health":{"Current":75,"Max":100}`, load restores values, re-save
  byte-stable.
- FieldMetadataTests: shape (16B, @0/@8/@12, enum 0..10) + live negatives
  (NOT_FOUND/NULL_ARG/BAD_ARG/OOB/re-describe) + Current f32 @0 / Max i32
  @4 readback.

## Gotchas
- `ComponentName<T>` was private: fixture assemblies compile against
  Engine.Runtime as a binary (no InternalsVisibleTo), so Describe must use
  a public cache. Made public deliberately.
- Unrunnable Register(null,null,null) must return -2 (existing test): guard
  Describe with `if (table != null && world != null)`, don't change the -2.
- CheckMover hand-built Health as 4B; the new 2-field Health is 8B —
  stackalloc byte[rows*8] + pointer writes.
- Bridge resolvers: thread_local staging vectors; the writer/reader consume
  rows synchronously within describe(), so reuse is safe.
- `std::memcpy` needs `<cstring>` in scene_json_read.cpp; `std::function`
  needs `<functional>` in the writer.
- Fixed-buffer mapping happens at IFieldSymbol level (IsFixedSizeBuffer +
  FixedSize), not in MapFieldType (which only sees the element type).

## P3-05 handoff
- Any described IComponent is inspectable via component_field_count/at +
  entity_get/set whole-struct read-modify-write. Undescribed components
  stay $bytes and are inspector-opaque. Type→control map: f32/i32/u32→
  NumericUpDown, bool8→CheckBox, vec3→3×NumericUpDown, quat→Euler degrees,
  color4→ColorPicker, entity→ComboBox, asset-ref→TextBox+drop.
