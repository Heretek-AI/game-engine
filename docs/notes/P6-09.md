## Design

Prefab asset = JSON file, subset of the P2-06 scene format:
```json
{"format":"engine-prefab","version":1,"entities":[
  {"id":1,"name":"Root","parent":0,"components":{...same component payloads as scenes...}},
  {"id":2,"name":"Child","parent":1,"components":{...}}]}
```
Same component payload rules as scenes (named built-ins, `$bytes` blobs,
P3-04 named user fields via describe callback). Extra rule: an entity may
carry `"PrefabRef":{"asset":"<path>"}` as a *sibling key of `components`*
(not a component) marking a nested-prefab mount point; its own
`components`, when present, are mount-point extras (name/pose) applied to
the nested root.

### Native module: `native/scene` prefab TU (`prefab.hpp` / `prefab.cpp`)
Free functions over `ecs_world_t*` + describe callback (no EditorSession
dependency, mirrors `scene_io.hpp` style):

- `save_prefab(world, root, path, describe, user)` — serialize the subtree
  rooted at `root` (BFS parents-before-children, same ordering as scenes).
  Nested-instance subtrees are NOT inlined: an instance root (carries an
  IsA link to a registered anchor) is written as a `PrefabRef` mount point
  (`{"asset":..., "overrides":{...}}`), so prefabs nest by reference.
  Live-instance overrides are computed by diffing live bytes against the
  registry base image (missing registry entry = not an instance = inline
  everything; keeps save usable outside instantiate flows).
- `instantiate_prefab(world, prefab_path, describe, user, registry, out_root)`
  — parse asset, materialize fresh entities (reuses the scene reader's
  per-entity materializer, refactored to a shared helper — reader
  behavior unchanged), then:
  - attach `(IsA, anchor(prefab_path))` to the instance ROOT only, so the
    existing `editor_is_prefab_instance` probe keeps working unchanged;
  - capture the base image (snapshot rows) into the registry under the
    instance root;
  - recurse into `PrefabRef` mount points (cycle-guarded: an asset already
    on the current instantiate stack resolves to an empty mount rather
    than recursing forever); nested roots register under their own asset.
- `update_prefab_instances(world, prefab_path, describe, user, registry)` —
  reload the asset, three-way merge per registered live instance:
  for each tracked entity/component/byte, `new = (live == base) ? asset : live`.
  Returns instances updated. Dead roots are pruned lazily.
- `apply_prefab(world, instance_root, describe, user, registry)` — write the
  instance's live subtree back to its asset file (nested links stay links),
  then rebase the base image to live (= overrides cleared).
- `revert_prefab(world, instance_root, registry)` — replay the base image
  onto the live subtree (respawn missing rows, drop extras outside nested
  links), i.e. overrides cleared by construction.

### Registry
`PrefabRegistry`: heap object owned by the bridge `EngineWorldImpl`
(like the P2-05 drain registry pattern — created with the world, torn down
in `ApiWorldDestroy`; prefab ABI entries resolve `EngineWorld*` -> impl ->
registry). Contents: `asset path -> anchor entity`, `instance root ->
{asset path, base-image rows}`. Anchors are flecs prefabs
(`ecs_entity_init` with `Prefab` semantics via `ecs_add_id(world, e,
EcsPrefab)`); instances carry `(IsA, anchor)`.

Per-field override granularity: base image stores raw component bytes;
diff/merge is per byte, but field-aware through the same lane logic as the
scene writer where needed. Acceptance test asserts per-field behavior on
LocalTransform lanes (position.x overridden, position.y follows asset).

### ABI tail (4.29, append-only after `input_lifecycle` @1376)
- `prefab_save(session, entity, path)` — subtree of entity -> asset file.
- `prefab_instantiate(session, path, out_entity)` — instantiate, root id out.
- `prefab_apply(session, entity)` — instance root -> write asset + rebase.
- `prefab_revert(session, entity)` — instance root -> restore base image.
- `prefab_update(session, path, out_updated)` — reload asset, merge all
  live instances, count out.
Session-based (not world-based): prefab ops are editor tooling and the
session already binds world + LocalTransform id; anchors live in the same
world. Return codes: 0 ok, ENGINE_ABI_ERR_* / negative scene codes.
