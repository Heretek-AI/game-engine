## 2026-11-01 — design: CPU cascade_shadow + test-local GLSL pair
- New engine module `native/renderer/{include/engine/renderer/cascade_shadow.hpp,src/cascade_shadow.cpp}` (auto-globbed into `engine_core_renderer`): 4-cascade split math mirroring `ShadowMapPlan` (lambda=0.5 log/uniform blend), per-cascade ortho fit in light space with **texel snapping** (center quantized to `texel_world` multiples, box snapped up to whole texels), PCF 3x3 CPU reference (`pcf_shadow`), cascade select (`cascade_index`), per-light `shadows_enabled` toggle (`shade_factor` returns exactly 1.0 when off).
- `static_assert` pins `kCsmCascadeCount == kShadowCascades`, `kCsmTileRes == kShadowTileRes`, `kShadowPcfTaps == 9` — drift fails the build.
- Deliberately did NOT extend `ShadowMapPlan` itself: its SDSM plan owns split math + atlas layout; the CSM module owns the light-space ortho fit + snapping. Shared constants asserted equal.
- Test-local GLSL (not engine frame — no engine pass draws directional shadows yet): `csm_depth.{vert,frag}` (R32F atlas prepass, analytic ground/pillar proxies) + `csm_shade.{vert,frag}` (analytic pillar scene, PCF 3x3 over cascade-0 tile, toggle). Compiled with system glslangValidator 15.2.0 `--target-env vulkan1.3`, embedded via `embed_spv.py`, mirrored into `include/.../shaders/` (dual-write convention from `slang_build.py`). Used distinct vert/frag stem names (`csm_shade_vert/frag`) after the first embed collided both stages onto one stem.

## 2026-11-01 — debugging (two real bugs, both fixed)
1. Segfault in `vkCreateGraphicsPipelines` on lavapipe: the checked-in `csm_shade_frag_spv.inc` was STALE (144B push block from the pre-shrink shader) while the layout declared 128B → VUID-10069, and the shade layout missed set 0 → VUID-07988. lavapipe segfaults where validation reports an error. Fixed by recompiling the `.inc` + declaring the layout as `[empty0, shade_set1]` (shader reads set 1). Lesson: re-embed `.inc` files after EVERY shader edit; run with `VK_LAYER_KHRONOS_validation` when a pipe create crashes.
2. `csm_shade.frag` used `(void)viewDepth;` — glslang rejects void-construction of float. Removed the variable; cascade selection documented as CPU-side.
3. Post pass layout: `post_composite.frag` reads set 1 (`hdrTex`/`hdrSmp`), so its layout is also `[empty0, post_set1]` with 2 sets bound — first attempt with only `post_set1` as set 0 tripped VUID-07988 the same way.
