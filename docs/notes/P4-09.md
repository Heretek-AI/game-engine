## Interface contract for the parallel P4-09 tasks (follow the P4-08/P4-10 pattern)

Established pattern (from `bloom.hpp`, `anti_aliasing.hpp` — read, not edited):
CPU-contract header owns the math with no GPU dependency (unit tests run
everywhere); test-local GLSL passes mirror it term-for-term; the golden
proves they agree. Toggle-off must reduce EXACTLY to the prior path
(bloom intensity-0 == P4-02 frame bit-for-bit via the same op order).

### 1. Half-res GTAO occlusion texture — format / size (t_390bf7c4 owns)

- Size: ceil-halving like `BloomMipSizes` (never 0): for a WxH frame the
  half-res target is `((W>1)?(W+1)/2:1) x ((H>1)?(H+1)/2:1)`. For the
  320x240 golden frame: **160x120**.
- Format: single-channel occlusion. Follow the `brdf_lut` precedent
  (`RG32F` float target); occlusion needs one float channel — use
  `VK_FORMAT_R32_SFLOAT` (or R16_SFLOAT if lavapipe precision proves out
  in the spike; record the choice). Linear 0..1, 1 = fully open.
- Content: GTAO from depth (+ normals as available) at half res, BEFORE
  blur. Expose the image + view through whatever handle the test TU owns
  (test-local passes, same as bloom/TAA — no new engine class needed
  unless the compositor wiring forces one).

### 2. Bilateral blur signature (t_55a30693 owns)

- Depth-aware separable blur of the half-res occlusion (H then V), edge
  weights from the half-res depth difference so silhouettes don't bleed.
- CPU reference shape (header, SDK-free, mirror in the `.frag`):
  `SsaoBlurTap(occlusion_center, occlusion_neighbor, depth_center,
  depth_neighbor, sigma) -> weight`; full-tap normalize. Exact sigma /
  tap count is the implementer's call — record in notes.
- Blur at half res, then bilinear upscale at composite time (no separate
  full-res blur target).

### 3. Composite hook (t_55a30693 owns)

- Composite multiplies the blurred occlusion into the shade-pass lighting
  (diffuse + specular IBL terms) BEFORE tonemap/exposure — same position
  as the bloom composite (`ldr = tonemap(lit * occlusion * exposure)`).
- CPU reference must mirror the `.frag` term-for-term, same as
  `BloomCompositeCpu`.

### 4. SSAO toggle plumbing preserving the P4-05 path (t_55a30693 owns)

- Toggle: `SsaoComponent`-style enable flag (follow `PostProcessComponent`
  16B blittable shape + `…Validate` clamp pattern) or a push-constant
  enable bit — implementer's call, but OFF must bypass GTAO + blur +
  composite entirely and reproduce the P4-05 golden
  (`p4_05_ibl_chrome_rough_320x240.png`) within golden tolerance
  (ideally bit-exact, like bloom's intensity-0 guarantee).
- Suggested CPU guarantee to mirror: `SsaoApplyCpu(lit, occlusion,
  enabled) = enabled ? lit * occlusion : lit` with the multiply SKIPPED
  (not `* 1.0f`) when disabled, so OFF is the identical op order.
