- Surprises (each cost real debugging time):
  - `gi_cornell.hpp` uses `std::uint32_t` → needs `<cstdint>` (P4-02's
    headers include it transitively; a fresh header does not).
    Fix: added the include.
  - `native/renderer` uses `file(GLOB CONFIGURE_DEPENDS)`: the new
    `gi_cornell.cpp` needed a re-run of `cmake --preset ci-linux`
    (re-glob) before the target would link — `cmake --build` alone said
    "no work to do".
  - Unused-function `-Werror` on `cornell_red_wall` helper + unused
    `check_tagged` in the TU: deleted both (Sonar/Clang gate).
  - SDF sign oracle on the OPEN red-wall quad: `sample_voxel(-1.9,1,0)`
    returns +0.806 (parity ray hits once → "outside"), not negative.
    The M3-04 oracle assumes closed meshes. P4-07 asserts
    `sample < kSdfBandVox` (inside the shell slab) instead — probing the
    probe denser: 0.1 m off-wall = 0.806, 0.5 m = 3.748, 1.0 m = 4.0
    (far-field fallback +band).
  - Meter-space lights lit nothing: the shade frame's scene space is
    PIXELS (P4-01: intensity 40000 at dist ~200; spheres at
    (160,120)). Meter-space key (0,1.8,0,i=30) gave a black floor.
    Fix: key (160,-120,220,i=40000) + bounce (30,150,60,i=12000,
    color 1.0/0.094/0.071 from the bounce albedo ratio).
