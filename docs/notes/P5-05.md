## Design (spec §6 P5-05 + rules 11, §7, AGENTS.md)

- `native/renderer/include/engine/renderer/particle_system.hpp`:
  `ParticleSystem` params struct (emission rate, burst count/interval,
  lifetime, start speed/size/color, gravity, color+size over lifetime,
  blend mode, capacity) + `Particle` SoA-in-struct record (pos[3], vel[3],
  age, life, size0, seed, color0[4]) + `ParticleSimulateCpu` reference
  (bit-exact contract for compute: same fixed-step Euler integrate, same
  PCG32 spawn RNG seeded per (seed, spawn_index), same fractional emission
  accumulator).
- Compute: `particle_emit.comp` (spawn up to budget into free slots via
  atomic counter on dead list) + `particle_update.comp` (Euler + gravity,
  life ramp, kill) — precompiled offline with glslangValidator to SPIR-V,
  embedded as `.inc` via `embed_spv.py` (same pattern as `cull.comp`).
- Render: point-sprite-expanded billboards into the P4-02 HDR target
  (`R16G16B16A16_SFLOAT`), one graphics pipeline for alpha blend +
  one for additive (`SRC_ALPHA, ONE`); CPU bitonic sort of draw indices
  by view depth for the sorted-alpha mode (deterministic, no GPU sort —
  10k keys sort in <0.2 ms on CPU, keeps lavapipe path simple).
- `ParticleSystem` ECS component registered via `RegisterRenderComponent`
  under `Engine.Runtime.ParticleSystem` + C# mirror in `Particles.cs`
  (blittable, size asserted in `RuntimeApiTests`/AbiLayout if applicable).
- Test `engine_particles` (`native/tests/test_particles.cpp`): CPU
  acceptance (rate 100 -> 100 ± 1 after 1 s fixed-step; CPU reference
  determinism: two runs same seed -> identical buffers) + GPU golden
  (60 fixed steps, `device_hint = "llvmpipe"`, `[FAIL]` under
  `ENGINE_REQUIRE_GPU=1` with no device, `SDL_VIDEO_DRIVER=offscreen`,
  golden `p5_05_particles_320x240` via `golden_compare.hpp` P1-05 tolerance).
- 10k stress: same TU records simulate+sort wall time for 10k particles
  over 60 steps and prints it (past in PR body); budget = under 8 ms/step
  host-side on the CI runner (state the number, no hard assert — lavapipe
  variance; the assert is determinism + count only).
