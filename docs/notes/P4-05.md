## 2026-11-06 — P4-05 review round: CodeRabbit + Sonar + macOS golden (t_d7b8095c, vulkan-renderer)

  - CodeRabbit Major (`ibl_shade.frag:84`): shade sampled the prefilter

    updated.

    `brdf_lut.comp` comments): dispatch docs now say ceil division
