## 2026-11-02 — extractor gotchas (3 iterations, all fixed)

1. `manual_snippets` + `manual_check` cannot share one project dir as two
   builds: stale `Generated/` breaks the extractor's own build
   (chicken-and-egg). Split: `manual_snippets.csproj` (extractor ONLY,
   `Compile Remove Generated`) + `manual_check.csproj` (compile gate,
   `EnableDefaultCompileItems=false` + explicit `Compile Include`).
   Also: two `.csproj` in one dir means `dotnet run --project <dir>`
   fails ("specify which project file"); CI and docs always pass the
   explicit `.csproj` path.
2. MSBuild error MSB4025: XML comments cannot contain `--`. Rewrote all
   csproj comments to avoid double hyphens.
3. Member-vs-statement heuristic: first version keyed on `using\s`,
   which matches `using var` STATEMENTS. Fixed with
   `using\s+(?!var\b|\()` lookahead. Type snippets (`public partial
   struct`) must compile NESTED, so the holder class is NOT static
   (CS0708 otherwise) — removed the `Staticize` pass.
4. `System.Text.Json.JsonObject` does not exist; corrected the manual
   fence to `System.Text.Json.Nodes.JsonObject` (compiles from the
   shared-framework ref pack, no package needed).
