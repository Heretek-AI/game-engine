## Discoveries (dated 2026-11-02)

- `CharacterVirtualSettings.mShape` is a `RefConst<Shape>`: a STACK
  `CapsuleShape` dies at `create()` scope end, leaving the
  `RotatedTranslatedShape`'s inner pointer dangling (SIGSEGV in
  `GetWorldSpaceBounds` on the first `ExtendedUpdate`). Jolt's own test
  heap-allocates (`new CapsuleShape`, refcounted). Fix: heap capsule +
  own `Ref<Shape>` member. Header stays Jolt-free via opaque
  `shape_buf_` (placement-new'd `Ref`, released in `destroy()` guarded
  by `character_ != nullptr`).
  Command: `gdb -batch -ex run -ex bt --args
  ./build/ci-linux/native/tests/engine_character_p6_04` ->
  `#0 RotatedTranslatedShape::GetWorldSpaceBounds ... #6 CharacterBody::move`.
- `PhysicsWorld::construct` already `RegisterDefaultAllocator`s (refcounted
  factory); a test-side `JPH::RegisterDefaultAllocator()` double-registers
  and segfaults at teardown. Fix: no test-side allocator call (matches
  `test_physics_joints` which calls it only because it builds bodies
  directly — here the world owns init).
- `move()` must NOT forward unbounded `vy_`: pressing into the ground
  banks fall debt (observed -78 m/s) and `WalkStairs` refuses the riser.
  Fix: clamp to a 10 m/s terminal velocity + re-anchor to the ground
  velocity when supported (Jolt test Step pattern).
- `WalkStairs` needs sub-stepping at game speeds: 1.5 m/s @ 60 Hz is
  2.5 cm/frame, but the riser up-sweep + forward probes assume Jolt-test
  step sizes (their TestWalkStairs runs 60/120/240/360 Hz). Sub-step to
  <= 1 cm per `ExtendedUpdate` (max 8 subs) — the wedge oscillation
  (x 3.68 <-> 3.71) resolves into a clean climb.
- `ExtendedUpdateSettings` forward probes are MAGNITUDES along the
  velocity direction, not vectors (`float`, not `Vec3`): first codegen
  attempt failed to compile (`assigning to float from Vec3`). Extended
  probe = radius + skin + 0.15, min-step 0.05.
- A lone vertical box face is NOT a stair: `WalkStairs` climbs stair
  treads, not razor faces (Jolt's TestWalkStairs uses a triangle-mesh
  flight, and `CanWalkStairs` needs an opposing steep contact). The AC
  scene is a 10-step mesh (tread == riser == 0.3 m, Jolt's exact
  triangle pattern rotated to climb +X); the assertion snapshots the
  first riser top (feet 0.3 +/- 0.05, support 0.3, grounded).
- `test_abi_layout` table size: 784 -> 840 (7 entries x 8B); offsets
  `character_create @ 784`, `character_get_pos @ 832`. `AbiLayoutTests`
  minor 11 -> 12 with matching offset pins.
- Prior run (attempt 1) left the worktree on a stale base (e7e3ec2,
  ABI 4.10 + foreign P2-03 commits) with an ABI-4.11-labeled character
  tail that collided with the merged P5-06 audio tail. Fix: reset to
  `origin/main` (6e8d790, ABI 4.11), re-applied the tail as ABI 4.12.
  No open PR touches `engine_abi.h` (checked `gh pr list --state open`).
