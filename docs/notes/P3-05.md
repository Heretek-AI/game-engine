# P3-05: Inspector panel (issue #91)

- Native tail (ABI 4.25, appended after the P3-04 4.24 field tail): `entity_remove` @1280, table 1288B (pinned in test_abi_layout + AbiLayoutTests). `GenericSystems::remove` (no-op when the entity lacks the row, so the undo stack never fails) + `ApiEntityRemove` (drops the run_systems lane plan like `ApiEntitySet`). Codegen: `EngineEntityRemoveFn` in the required-entries list. This slice has no other ABI surface: SetFieldCommand reads/writes through `entity_get`/`entity_set` + the P3-04 `component_field_count`/`field_at` readback.
- Port note: the Oct-31 P3 stack branch (`parity/p3-05-inspector-panel`, 31c673b) drafted this against ABI 4.5 (remove @424, table 432B) on a tree where `construct()` registered render components and `field_at` used out-params. On current main the world does not pre-register render components (registration resolves lazily through `Ecs.ComponentId<T>`, same idempotent lookup), `field_count` returns the count and `field_at` fills a `FieldDesc` struct, so `ComponentFields.ReadAll` follows the current shape. `mesh_id` reads as u32 (an 8B asset-ref lane @0 would overlap `base_color` @4 and `describe` rejects it); the scene JSON writer keeps its bespoke mesh-by-asset-ref path. `EditorSession.World` stays public (P1-10 renderer borrowing); the P3-08+ `DropAsset`/`DeleteEntity` members are untouched.
- Managed (`Engine.Editor`): `FieldValue` codec (all 11 ENGINE_FIELD_* types; `ByteSize` lane table; `ReadFloat/WriteFloat` with per-type lanes; `ReadBool/WriteBool`; `ReadId/WriteId` for entity/asset-ref u64; `QuatToEulerDeg`/`EulerDegToQuatValue` in ZYX yaw-pitch-roll convention, round-trip dot > 0.9999 for 10/20/30 and 45-deg yaw; identity ~0). `SetFieldCommand(session, entity, component, field, before, after)` — whole-image read-modify-write (`ReadImage`: LocalTransform routes through `editor_get_local` lane packing @0/16/32, everything else through `entity_get`); `AddComponentCommand` (zeroed image via `entity_set`; revert via `entity_remove`; LocalTransform structural via `EnsureLocal`, never removable); `RemoveComponentCommand` (snapshots via `entity_get`, removes, replays on undo). `EditorSession.World` (borrowed native world) + `HasComponent` (LocalTransform via `editor_get_local` probe, rest via `entity_get` rc) + `FieldsOf` (via `ComponentFields.ReadAll`) + private `ResolveComponent` (align 64 for LocalTransform, 4 otherwise — gotcha 20).
- Panel (`Engine.EditorApp/InspectorPanel.cs`): one `Expander` per registered component (`Component_{name}`) with the entity id/name header; per-type editors (`TextBox` f32/i32/u32 + vec lanes + Euler degrees + RGBA color lanes with a live swatch `Border`; `CheckBox` bool8; entity `ComboBox` over the hierarchy walk with `DropDownClosed` commit; asset `TextBox` + `engine-asset-id` drop target). Every commit goes through `Inspector.Execute` (one undo step per `LostFocus`/Enter, never per keystroke; Escape reverts the box). Add Component button lists `KnownComponents` (LocalTransform, Camera, MeshRenderer, DirectionalLight) and skips present rows; per-section `Remove Component` context entry.
- Acceptance: `Engine.Tests` CPU (`FieldValue` f32/i32/bool/entity-id round-trips, 45-deg yaw + 10/20/30 euler-quat, identity, vec3 lane OOB throws, `SetFieldCommand` ctor guards) + live (`SetFieldCommand` position.x = 2.5 → undo → redo, MeshRenderer describe 2 rows + base_color.r edit + remove/undo/redo). `Engine.EditorApp.Tests` headless (`InspectorPanelGolden`: spawn Cube, `AddComponentCommand` MeshRenderer, focus `Edit_position` → `2.5` + Enter → `GetLocal` reads 2.5 with one undo step, Ctrl+Z restores, `editor_inspector_lm` golden of LocalTransform + MeshRenderer). Native `engine_inspector_edits` ctest (float-lane edit, undo replay, remove + re-add, double-remove no-op).
- Verification: `dotnet build Engine.slnx -c Release` clean, `dotnet format --verify-no-changes` clean, managed 1108 PASS live (exit 134 = pre-existing post-run teardown crash, also present without this slice — baseline exits 3 with ABI-mismatch skips), native `engine_abi_layout` 328 PASS + `engine_inspector_edits` all PASS. `engine_core` rebuilt with `DOTNET_ROOT=/usr/share/dotnet` (this container has no `~/.dotnet/packs`; the bridge CMake falls back to `$HOME/.dotnet` and fails the link otherwise).
- Gotchas: (1) `Key` is ambiguous between `Avalonia.Input.Key` and `Engine.Runtime.Key` in both panel and golden files — alias `using Key = Avalonia.Input.Key;`.
