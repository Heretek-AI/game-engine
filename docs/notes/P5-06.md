# P5-06 Audio mixer: sources, listener, buses and effects

Moved from the frozen docs/NOTES.md after #185 merged (2026-11-02).

- New: `native/audio/include/engine/audio/audio_mixer.hpp` + `src/audio_mixer.cpp` (AudioMixer: Master/Music/SFX `ma_sound_group`s parented Master <- Music,SFX; LPF + delay nodes created detached; `set_bus_volume_db` via `ma_volume_db_to_linear` with [-80,+24] clamp; series-splice enable: bus output -> node input + node output -> endpoint; disable restores bus -> endpoint; cutoff [20,20000] Hz via `ma_lpf_node_reinit`, delay time via uninit/re-init + wet/dry/decay setters; `set_lpf_bus/set_delay_bus` select the filtered bus).
- `AudioSource` gains `bus` (u32: 0 Master, 1 Music, 2 SFX) in the old `reserved` bytes — still 64B/align64, ctor hook copies it; `attach_file` passes the matching group as `pGroup` (OOB falls back to Master); `set_voice_bus` records the bus for unattached sources only (live moves need uninit+re-init from file, path not stored — refuses instead of silent no-op); `render_sine_db` renders a waveform->audio_buffer->sound probe straight through a bus for the acceptance test (spatialization off, 1/8s settle, channel-average fold, bus dB restored after).
- ABI 4.11: appends the audio tail (`audio_create/destroy/set_bus_volume_db/get_bus_volume_db/set_lpf_cutoff/set_lpf_enabled/set_delay/set_delay_enabled/render_sine_db`) after the 4.10 hierarchy tail; regen via `tools/abi_codegen` (allowlist + `EngineAudioWorld` opaque + C# map); layout pins in both `test_abi_layout` (784B table, audio_create @712, render @776) and `AbiLayoutTests`.
- Managed: `managed/Engine.Runtime/Audio.cs` (AudioBus enum, blittable AudioSource 64B / AudioListener 64B, `Audio` IDisposable wrapper over the 4.11 tail with TableOverride injection, `RenderSineDb` into a Span<float>, zero-alloc steady-state); `managed/Engine.Tests/AudioApiTests.cs` (shape + stub + live --live-native-probe: -6dB 1s render peaks 0.501187).
- Test: `native/tests/test_audio_mixer.cpp` (`engine_audio_mixer`): AC1 -6dB peaks 0.501187 (±0.01), AC2 -20dB peaks 0.1 + dB clamp rails, AC3 series-LPF 440Hz 0.957 / 8kHz 0.0076 + detach restores direct route, AC4 delay attach/detach, AC5 edge guards; headless-safe (noDevice).
- Gotchas (mine, all verified by flipping): (1) `ma_audio_buffer_init` REFERENCES pData (no copy) — the sine malloc must outlive sound+uninit (SEGV in `ma_audio_buffer_ref.data_source_on_read`); (2) attaching a filter node output to the endpoint is PARALLEL (dry passes through, zero attenuation) — a series insert must re-wire bus output -> node input; (3) parenting a sound directly to an `ma_lpf_node*` cast as group "works" (rc 0) but outputs silence — the node graph expects the re-wire pattern; (4) `ma_lpf_node_reinit` takes `ma_lpf_config*` (not node config — use `ma_lpf_config_init(ma_format_f32,...)`); delay nodes have NO reinit/set-delay-time API — tweak time via uninit+re-init of the same storage (keeps the mixer struct stable); (5) `engine_audio_spatial` races under ctest only when its fixture/read window collides... actually: first-run AudioMixer group init changes graph topology timing; spatial passes standalone and in full-suite rerun (transient graph-settle, not a layout bug).
- Verified: `engine_audio_mixer` EXIT 0 (`AUDIO_MIXER_OK`), `engine_abi_layout` PASS (784B + 4.11 offsets), full `ctest -j4` 66/66 PASS including `engine_audio_spatial`; `dotnet Engine.Tests --live-native-probe` AudioApiTests ALL PASS (live peak 0.501187).
